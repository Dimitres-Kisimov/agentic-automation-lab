# Token & cost model

Unit economics of the automation flows, run over the 9 offline task fixtures (`eval/tasks/*.json`) with the deterministic mock provider, priced against `eval/pricing.json` (list prices as of **2026-06-24**, USD).

> **What these numbers are — and are not.** Tokens are the **mock chars/4 estimate** in `llm.py`, not a real tokenizer, so this is an order-of-magnitude planning model of the loop's shape — **not a bill**. Real token counts and cost only appear under `LLM_PROVIDER=anthropic`. **No prompt caching** is modelled (the loop resends the full transcript each turn, so input tokens reflect the *uncached*, expensive case; caching bills cached input at ~0.1x). **Latency is excluded** (non-deterministic — see `benchmarks/run_benchmark.py`). List prices change and partner platforms price differently.
